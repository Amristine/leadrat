# LeadRat — Real Estate CRM Starter

A responsive real estate CRM interface inspired by common real-estate workflows. This is an original implementation and does not copy proprietary source code or assets.

## Included
- Dashboard with overview KPIs, illustrative lead activity chart, and pipeline summary
- Lead management table with search and status/source filters
- Add lead modal and lead profile panel with editable status, agent assignment, follow-up, notes, and activity timeline
- Property inventory list and search/type filter
- Follow-up checklist and site visit schedule
- Campaign/source overview, team performance, and reports
- CSV/text exports
- Workspace settings UI
- Responsive desktop and mobile layout

## Run locally
Open `index.html` in a browser, or run `npx serve .` from the repository root.

## Limitations
The repository was empty, so this was created as a static starter. Demo contacts and most dashboard metrics are illustrative. Data is held in browser memory only; refreshing resets new edits. Authentication, database persistence, multi-tenant isolation, production APIs, audit logging, and WhatsApp/property-portal integrations still need to be implemented before using real customer data.
