# LeadRat — Real Estate CRM Starter

Responsive real estate CRM starter inspired by common real-estate workflows. This is an original implementation and does not copy proprietary source code or assets.

## Preview
Open `index.html` in a browser, or run `npx serve .`.

## Modules planned
- Dashboard and pipeline metrics
- Lead management with search, filters, statuses, assignment, and lead profile timeline
- Property inventory
- Follow-ups and site visits
- Campaign/source reporting
- Team performance and settings

## Current scope
This repository was empty, so this starter is being added from scratch. Sample metrics and contacts are illustrative. This static version demonstrates UI and local interactions only. Authentication, database persistence, tenant isolation, production APIs, and WhatsApp/property portal integrations must be implemented before using real customer information.
